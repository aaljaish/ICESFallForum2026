# Presentation preferences

- Reveal distinct points and visual elements one at a time on a mouse click whenever this supports the explanation.
- Keep each visible slide state focused and readable. Split long prompts or dense content into successive views or additional slides so the audience can follow without feeling overwhelmed.
- Use the presenter's original prompt wording when supplied. Stage long prompts in meaningful parts while retaining the full text.
- Use section divider slides when introducing a new topic.
- Preserve click and keyboard navigation, and check the visible reveal states when editing interactive slides.
